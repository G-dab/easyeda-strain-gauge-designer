# v0.2.1 — Early access / 体验版

A parametric metal strain-gauge designer for JLCEDA / EasyEDA Pro desktop. The UI is currently in Chinese; the repository provides English and Chinese READMEs.

## Install

1. Download `strain-bridge-designer_v0.2.1.eext` from Assets. `SHA256SUMS` contains its SHA-256 checksum.
2. Import the extension in JLCEDA / EasyEDA Pro desktop (target version 4.1.60 or later).
3. Open a separate PCB document, then choose **应变片设计 → 打开设计器**.
4. Before manually wiring an external terminal, disable **布线 → 移除回路** (Routing → Remove Loops). The bridge intentionally contains resistive copper loops.

## Included

- Four-quadrant bridge geometry and four-stage drawing.
- Bottom solder pads or dimension-defined FPC contact fingers, with adjustable terminal order.
- Ordered 45° lead routing, optional back-layer leads and vias, and independent front/back preview.
- Configuration save/readback, explicit rebuilding and preservation of existing 0.2.0 routing until rebuilt.

## Validation and limits

This is a **pre-release** for trial use and feedback. Twenty software tests cover geometry, both terminal types and all 24 terminal orders, layer connectivity, manual-edit protection and recovery. EDA API tests use simulated interfaces. Browser/package checks have passed; full native drawing, saving and readback remain to be verified. A user confirmed that disabling Remove Loops preserves the bridge during manual wiring.

Resistance values are nominal copper-geometry estimates. Manufacturing stack-up, via process, contact plating and reinforcement require separate setup. Sensor sensitivity, temperature behavior and calibration are outside this project.

## 中文说明

本次是面向试用与反馈的 **v0.2.1 预发布版**。下载附件中的 `.eext` 并在嘉立创 EDA 专业版扩展管理器导入即可，无需为安装预构建插件额外配置 Node.js。源码构建和浏览器预览步骤见仓库 README。

主要功能包括四象限桥芯、分阶段绘图、下方焊盘／FPC 金手指、接点排序、45°规整引出、可选背面与过孔、配置回读和明确重建。

**手动接线前必须关闭“布线 → 移除回路”**，避免 EDA 自动删除有意保留的桥体回路。已有 0.2.0 图形会继续保留，明确重建外部引出才切换新路由。

20 项软件测试已通过，EDA API 测试使用模拟接口；完整客户端绘图、保存和回读仍需继续验证。本项目不评价实测灵敏度、温漂或标定效果。
